# MindScope 🧠

Explore reasoning, working memory, focus, emotional intelligence, and creative flexibility through short interactive activities.

## Features
- Five assessment areas with answer feedback and explanations
- Session summaries, scores, and completion times
- Results history stored locally in your browser
- Export your results as JSON and clear saved history
- Responsive layout with dark/light modes and customizable accent colours
- Comfortable or compact interface density, plus reduced-motion preference
- No account or backend required

## Run locally
Open `index.html` in a modern browser. Your preferences and results stay in that browser's local storage.

## Publish with GitHub Pages
A workflow is included at `.github/workflows/pages.yml`. In the repository, open **Settings → Pages** and set the build/deployment source to **GitHub Actions**. If GitHub asks you to authorize Pages or create the `github-pages` environment, follow its prompts. Pushes to `main` then trigger deployment. Check the **Actions** tab for the workflow status and live URL.

## Important limitations
MindScope is an educational self-assessment, not a professionally standardized IQ test or clinical instrument. Its short tasks cannot establish an official IQ score, diagnose ADHD or another condition, or prove exceptional/special abilities. Emotional and creative results are especially limited reflections, not validated measures.

## Privacy
No application server is used. Assessment history and preferences are saved in the current browser profile. Other people who use the same browser profile may be able to access them. Exported JSON files may contain your answers and session timestamps, so store them thoughtfully.
